# Canvas Assignment Comments Downloader

## Overview
These scripts create a report containing submission comments from a specified Canvas assignment (or all assignments) from a specified Canvas course.\
\
Please note: The group comment report DOES contain numerical grades, so be sure not to share it with non-authorized individuals. Always follow FERPA guidlines. 

## Requirements

- Python 3.x
- [`canvasapi`](https://github.com/ucfopen/canvasapi) Python library
- A valid `config.json` file with your Canvas API credentials

## Installation

1. **Clone or download the script.**
2. **Install required Python modules:**
   ```
   pip install canvasapi
   ```
3. **Update `config_template.json` with your Canvas API and course ID and rename it `config.json`**

- To get a Canvas API, go to your Canvas account (profile picture) > Settings > "+ New Access Token" (at the bottom fo Approved Integrations section)
- Your Canvas course ID is a 6 digit number that can be found in the URL on any Canvas page in that course: https://umich.instructure.com/courses/######

## Usage

1. **Run the script:**
   ```
   python3 indiv_peerfeedback_comments.py
   ```
   or
   ```
   python3 group_grades_comments.py
   ```
   (you can give the files shorter names if you want to make it easier on yourself)
2. **Input:** When prompted, enter a single assignment number (7 digit number in URL: assignments/#######) for which you want to download comments, or (for the individual comment script) type `all` to download comments for all assignments.

3. **Output:**  
   The script saves the organized comments in the `output/` folder. The filename is automatically generated, e.g.:  
   ```
   mycoursename_assignmentname_comments.txt
   ```

## Output Format (Individual)

The report is organized by commenter. Each commenter is listed, followed by the name of the original submission’s author, and then the comments. This report does not contain numerical grades. Example:
```
Commenter: Jane Doe

Commenting on: John Smith
Comment: Great work on the introduction!

Commenting on: Emily Davis
Comment: Please clarify your thesis statement.

...

```
If you choose to download comments for all assignments, the comments will be organized by assignment, then by commenter. The name of each assignment will be written in all caps, followed by all of the comments for that assignment. 
```
ASSIGNMENT NAME

Commenter: Jane Doe
...
```
## Output Format (Group)
The report is organized by original submission group. The group name is provided, followed by the names of the group members, the total grade, the name of the grader, rubric scores, rubric comments, and finally the overall assignment comment. Example:
```
Group: Team Awesome
Members: Jane Doe, John Smith, Emily Davis
Score: 85.0
Grader: Professor Joe 
Rubric:
  - Rubric criterion 1:  [Score: 35.0]
  - Rubric criterion 2:  [Score: 30.0]
  - Rubric criterion 3:  [Score: 20.0]

Rubric comments:
 - Rubric criterion 1: Your introduction is strong. 
 - Rubric criterion 2: Some sources on the reference list weren't cited.
 - Rubric criterion 3: Visuals look great!

Assignment comment: Great work overall!

...

```
